# P1.2 航行与接触观测原型

状态：P1.2 局部实现，2026-09-28。沿用 `p1-world.md` 的固定地图；美学方向参考 `archipelago_echoes_aesthetic_plan.md`。

## 舰艇与时钟

- 海岬号初始航向 000°，航速 0 kn。000° 指北、090° 指东。按钮每次转向 15°、调速 5 kn，最高航速取舰艇定义中的 22 kn。该控制步进是可替换的原型值，未作为正式操纵规则确定。
- 舰艇按世界时钟推进，1 kn = 1.852 km/h。暂停时位置不变；暂停时下达的航行命令在恢复后执行。
- 每段位移先检查地图边界和岛屿。若航路被挡，本帧不移动、航速归零，界面和事件日志显示受阻。当前没有搁浅伤害、绕航或惯性模型。

## 雷达信息

- 样例接触占据固定世界位置；发现和更新扫描读取当时本舰与接触的相对方位、距离及模拟时间。已报告的数值保持到下一次扫描，避免在扫描间连续暴露精确位置。
- 雷达标记以最近一次观测的世界位置为基准，随本舰移动而改变相对屏幕位置。失联后隐藏标记，详情保留最后一次观测与“未确认”状态。样例的三段扫描周期仅用于验证发现、更新、失联反馈，不模拟真实雷达概率。
- 视觉使用深绿 CRT、低亮网格、蓝色本舰航向、绿色未知回波与琥珀色重点提示；通信日志使用短句显示操作结果。颜色之外仍以文字区分状态。

## 验证与边界

`tests/p1_navigation_smoke.gd` 检查可见控件发令、航速换算、暂停、扫描前后读数、撞岛停车、失联信息与目标窗口内控件布局。Godot 无窗口模式可验证场景加载与布局数值，不能代替实际屏幕的视觉检查。

接触识别、敌方移动、武器、伤害和海空切换仍未实现，P1.2 阶段出口尚未满足。
