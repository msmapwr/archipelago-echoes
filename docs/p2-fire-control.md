# 雷达距离档与舰炮射界

2026-10-06 的局部 P2 原型。参考 `plan-legacy.md` 第 11 节的雷达距离档，以及扩展武器规则中的扇形射界、火控和装填反馈。数值采用可替换的原型规则。

雷达页脚的“量程”按钮在 25 km 搜索视图与 12.5 km 近距视图间切换。近距档会放大附近回波、岛屿和武器范围，视图外的移动目标不绘制也不可点击；若原选中目标移出视图，会取消选择。传感器记录保持不变，切回 25 km 可重新选择。距离档不增加探测能力，静默仍会停止实时扫描。

甲板炮射程为样例武器数据中的 10 km，射界为舰艏左右各 70°。玩家需要转向，让最后有效观测的目标方位进入射界。雷达上的范围弧与边界线随舰艇航向转动；可开火时呈绿色，当前有条件未满足时呈琥珀色。该扇形仅标示几何范围，岛屿遮挡仍由火控规则检查。

火控栏、按钮提示与实际射击共用同一套条件检查：指挥模式、暂停、雷达开关、选中接触、识别、弹药、装填、射程、情报时效、射界和岛屿遮挡。失败会说明原因且不扣弹。命中后每次消耗一发，装填 30 模拟秒；暂停冻结倒计时，10 倍时间按模拟时间推进。

回归覆盖转离目标后的射界拒绝、弹药保护、转回后的有效命中、距离档对传感器记录的保护，以及射击后的 UI 装填状态。提前量、锁定照射、近失弹、校射、多炮位、增益和杂波仍待后续开发。
