# 雷达距离档与舰炮射界

2026-10-06 的局部 P2 原型。参考 `plan-legacy.md` 第 11 节的雷达距离档，以及扩展武器规则中的扇形射界、火控和装填反馈。数值采用可替换的原型规则。

雷达页脚的“量程”按钮在 25 km 搜索视图与 12.5 km 近距视图间切换。近距档会放大附近回波、岛屿和武器范围，视图外的移动目标不绘制也不可点击；若原选中目标移出视图，会取消选择。传感器记录保持不变，切回 25 km 可重新选择。距离档不增加探测能力，静默仍会停止实时扫描。

甲板炮射程由样例武器数据定义，当前为 12 km（旧文档曾写 10 km），射界为舰艏左右各 70°。玩家需要转向，让最后有效观测的目标方位进入射界。雷达上的范围弧与边界线随舰艇航向转动；可开火时呈绿色，当前有条件未满足时呈琥珀色。该扇形仅标示几何范围，岛屿遮挡仍由火控规则检查。

火控栏、按钮提示与实际射击共用同一套条件检查：指挥模式、暂停、雷达开关、选中接触、识别、弹药、装填、射程、情报时效、射界和岛屿遮挡。失败会说明原因且不扣弹。命中后每次消耗一发，装填 30 模拟秒；暂停冻结倒计时，10 倍时间按模拟时间推进。

回归覆盖转离目标后的射界拒绝、弹药保护、转回后的有效命中、距离档对传感器记录的保护，以及射击后的 UI 装填状态。提前量、锁定照射、近失弹、校射、多炮位、增益和杂波仍待后续开发。

## P2.1：甲板炮目标指派切片（2026-10-11）

原文未单列 P2.1。本切片以现有一艘母舰、一门甲板炮与 A1 接触为边界，建立完整的选择 → 指派 → 火控检查 → 手动射击 / 撤销 → 归档流程。保留当前资源射程 12 km、舰艏 ±70°、30 模拟秒装填、每发 50 伤害与任务胜利条件保持。

### 交互及生命周期

- 在舰桥选择 A1，至少两次有效扫描并确认身份；点击“指派目标 → 甲板炮”。允许在射程/射界外指派，随后调整航向或位置。指派不扣弹、不造成伤害、不推进时间。
- 选择仅供查看。ESC、点击空白、切换量程或目标移出视图取消选择时，甲板炮的指派仍保留；火控栏和独立方框显示指派，选中圈不等于火控锁定。
- 点击“甲板炮”只对已指派目标执行一发射击；点击“撤销指派”清除命令。重复指派同一目标不生成新编号。撤销/重新指派不能重置弹药或装填。
- 暂停时允许指派和撤销；射击仍被拒绝。关闭命令档案/图鉴保留原有暂停状态与指派。
- 出击配置、移交、座舱与返航保留指派但暂停舰炮指挥；托管不自动开火。实际回舰后才重新允许舰炮指挥。
- 雷达静默、失联或观测超过 45 秒阻止射击但不撤销指派；重新取得有效观测后再次检查。恰好 45 秒仍有效。
- 目标失能、母舰沉没、任务结算或失败清除指派；重开关卡重置编号与状态。结束后不能下达新命令。

### 状态与信息边界

`MissionController.fire_control_target_id` / `fire_control_order_id` 是指派的权威状态；UI 不写入它们。`assign_fire_control_target(id)`、`clear_fire_control_target()` 和 `fire_ship_gun()` 是命令入口。所有实际射击经过 `ship_gun_block_reason()`，状态栏/扇形使用同一检查。

范围、射界、岛屿遮挡使用最后有效观测坐标与当前己舰位置，禁止用隐藏敌舰实时坐标更新射击条件；仍沿用原型的确定性直接伤害，不提供运动预测或弹道模拟。

兼容迁移：`fire_ship_gun(id)` 的显式参数保留，但不再隐式把查看目标当作指派；必须先调用指派入口，且参数必须匹配已有命令。现有战斗回归增加该前置步骤，原射程、时效、射界、装填及损管断言保留。

### 归档与任务指引

指派、撤销、指派/撤销拒绝、射击拒绝和成功射击记录进入 `EventBus.history`，带模拟时间；有效命令和射击记录关联目标、武器及指派编号，射击还记录观测时间与瞄准坐标。命令编号不会被重复指派刷新。

F1 命令档案保留原三页，增加“火控命令”：当前指派、打开前的火控条件和最近 40 条火控记录；全部行动记录也展示关键火控操作。任务指引保持原阶段和五个任务里程碑，舰桥额外给出指派/阻塞/手动射击建议；警报优先。击沉 A1 或执行火控命令不是侦察任务的新增胜利条件。

### 验收清单

1. 未识别、无接触、错误 ID、过期观测或无舰桥指挥权不能指派；失败不改原指派或资源。
2. 选择/取消选择/量程与指派独立；暂停排队、撤销、重复命令、海空移交/回收、目标失能和结束/重开均遵循上述生命周期。
3. 指派后手动射击仍服从静默、失联、情报时效、弹药、装填、损管、范围、射界、遮挡和暂停规则；失败不扣弹，成功每次一发；重新指派不绕过装填。
4. 历史和火控页能关联同一个命令的指派、射击、拒绝与撤销；打开/关闭档案不改变模拟资源和任务判定。
5. 现有 M0/M1、导航、图鉴、损管和 UI 回归保持通过；实际 CRT 检查按钮与告警布局。自动测试不能代替真人判断压力评估。

不在本切片：多目标/多炮位分配、持续锁定照射、自动/连续射击、提前量、近失弹、校射、火控雷达新资源、弹道和随机命中。后续按这些机制各自带来的决策与反馈再拆分 P2.2。
