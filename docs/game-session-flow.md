# 完整游戏流程框架

2026-10-06。按用户要求，先预留游戏从开始到结束的环节，暂不展开完整内容。

## 状态与入口

`console_shell.gd` 管理会话外层的 `session_stage`；现有 `GameManager.mode` 继续管理舰桥、驾驶舱、返航和任务结果。准备页由 `session_preparation.gd` 管理，不启动任务模拟。

| 状态 | 当前行为 | 后续接入 |
| --- | --- | --- |
| menu | 唯一“开始游戏”按钮；模拟暂停 | 保持现有主菜单 |
| opening | CRT 亮屏过渡，可继续 | 开场动画、音效、跳过 |
| settings | 默认配置说明占位 | 显示、音量、按键设置与保存 |
| background | 剧情入口占位 | 世界背景、角色与行动缘由 |
| tutorial | 现有操作提示 | 交互演练、步骤验证与重播 |
| orders | 展示现有首关命令并接受 | 指令部简报与任务数据绑定 |
| generation | 固定首关配置说明 | 种子、生成进度、错误恢复 |
| harbor | 出航确认占位 | 港口生成、解缆、驾驶驶出航道 |
| mission | 确认出航后载入现有首关并恢复时间 | 真实离港触发正式任务 |
| completed / failed | 现有结算／失败报告，可重试或返回菜单 | 战役推进与最终结局 |

主流程：开始 → 开场 → 设置 → 背景 → 教程 → 接受命令 → 生成 → 港口出航 → 正式任务 → 结算／失败 → 主菜单。

## 当前约束

- 准备阶段始终冻结世界时间，任何一步都可返回主菜单；再次开始从开场进入。
- 只有港口页确认才能启动首关。数据加载失败保持准备页并显示错误，可返回菜单重试。
- “场景生成”页不声称已经实现随机生成；“港口出航”页不声称已实现港口驾驶。
- 成功或失败后均可返回主菜单，卸载任务 CRT 并暂停世界；重试按钮暂保留现有直接重开首关行为。
- 完整战役、最终结局、存档与设置持久化尚未实现。会话完成目前指现有单关结算。

## 开发顺序与验收

1. **流程骨架（已接入）**：七个准备页面依序可达；确认前时钟冻结；命令先于出航；结算和失败都提供出口；再次开始清除旧页面。
2. **真实出港**：定义港口出生点、航道与离港边界；先在港口驾驶，再触发正式任务，离港前禁止战斗系统启动。
3. **生成与设置**：生成成功才允许出港，失败可重试；设置能够应用、保存并恢复默认。保持现有固定地图回归入口。
4. **动画、叙事、教程**：沿用美学计划制作内容；教程验证实际操作，支持跳过和重播，不强制重复。
5. **战役结束**：接入连续任务和最终结局，区分单关完成、战役胜利与永久失败，按总计划处理继承与存档。

自动验证覆盖准备次序、暂停、出航启动、失败返回和取消准备；图形回归覆盖首关成功结算、重试与既有战斗操作。港口驾驶等未实现环节不能据此宣称验证完成。
