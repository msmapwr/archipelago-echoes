# 完整游戏流程框架

2026-10-06。按用户要求，先预留游戏从开始到结束的环节，暂不展开完整内容。

## 状态与入口

`console_shell.gd` 管理会话外层的 `session_stage`；现有 `GameManager.mode` 继续管理舰桥、驾驶舱、返航和任务结果。准备页由 `session_preparation.gd` 管理，不启动任务模拟。

| 状态 | 当前行为 | 后续接入 |
| --- | --- | --- |
| menu | 唯一“开始游戏”按钮；模拟暂停 | 保持现有主菜单 |
| opening | CRT 亮屏过渡，可继续 | 开场动画、音效、跳过 |
| settings | 音量、窗口、全屏、弱化 CRT，应用保存和默认草稿 | 按键重绑与分音轨音量 |
| background | 任务资源中的背景原型，可滚动阅读 | 正式时代、阵营与长篇剧情 |
| tutorial | 七步交互训练、条件验证、跳过与重播 | 更接近实际航行与飞行的训练场景 |
| orders | 任务数据驱动简报、目标、舰机与注意事项；有效命令接受保护 | 多任务选择与指令部任务系统 |
| generation | 指定／随机种子、五岛生成、校验与重试 | 更完整的地形、港口和任务生成 |
| harbor | 港口驾驶说明与进入确认 | 港口背景与简报深化 |
| harbor_navigation | 固定港区、解缆、转向、航速、碰撞、离港线 | 更精细的港口地图与舰船操纵 |
| mission | 实际离港后启动；继承航行命令，固定目标提示与随时查看的命令档案 | 战役任务衔接 |
| completed / failed | 现有结算／失败报告，可重试或返回菜单 | 战役推进与最终结局 |

主流程：开始 → 开场 → 设置 → 背景 → 接受命令（教程默认跳过，可手动打开） → 生成 → 港口准备 → 解缆并驾驶离港 → 正式任务 → 结算／失败 → 主菜单。

## 训练与简报（2026-10-07）

- 教程默认跳过，背景／命令页可手动打开。主动进入后必须完成全部七步，或明确点击“跳过训练”，才能继续。全部完成后独立保存本地记录；仅主动跳过不会保存完成记录。“重播训练”清除本次练习并重新关闭继续入口，但不撤销已保存的完成记录。
- 扫描产生 A1 回波，点击回波或“选择 A1”后，第二次扫描才能确认；最新观测超过 15 秒需要重新扫描。炮击演练仅对训练敌舰开放。随后练习航向、航速、暂停恢复，最后依次模拟出击、返航、降落。
- 训练时钟只在训练页可见且未暂停时推进，余辉使用已有衰减函数；演练不修改正式世界、事件、弹药、舰体、燃油或识别标记。训练操作立即演示状态，不模拟正式切换等待、航迹、武器装填或降落条件。
- 背景和命令绑定 `TaskDefinition` 新增的可选文字字段，现有数据格式保持兼容。背景为原型文案，正式年代和阵营尚未决定。命令接受时校验任务与舰机接触引用，生成和港口还会检查接受状态；数据失败可返回菜单重新准备。
- 简报明确首关是“识别并安全回收”，不要求击沉目标；说明母舰风险与当前友方机场备用回收的原型规则，避免训练炮击被误解为任务完成条件。

## 任务内引导与档案（2026-10-07）

- 主 CRT 顶部固定显示当前目标和行动提示；按实际任务标记推导搜索、识别、出击、移交、侦察、返航、回收和报告阶段，舰炮或空袭击毁不替代首关目标。
- 页脚“命令档案”或 F1 打开简报、任务进度与行动记录；ESC、F1 或关闭按钮返回。档案打开时暂停模拟，关闭时只恢复由档案自己开启的暂停；原本手动暂停、结算或失败保持冻结，倍率不变。TAB 和方向键在档案按钮内循环，空格不会恢复背后的模拟。
- 五项检查展示实际观测、识别、升空、回收与报告。行动记录显示最近 40 条模拟时间戳，省略重复复测；档案按打开时状态生成，阅读中冻结世界。
- 返航提示与真实降落条件一致：母舰 2 km 且不超过 12 kn，机场 3 km。燃油警报使用当前速度到可用回收窗口的直线时间加两分钟余量，仅是原型提示，不保证移动母舰或操纵后一定可达。
- 提前回舰可继续扫描识别；未识别即降落机场时，当前原型无法重新起飞补做侦察，提供重新开始或返回菜单。失败显示已记录的失事原因，重试清除出击次数与失败原因。

## 会话约束

- M0/M1 加固后，出击配置可选择保持母舰航行或实际升空后停车；移交期间继续最后命令。飞机在空中可请求母舰停车，返航可取消继续侦察，不重置位置和燃油。暂停仅允许排队航行／导航等命令，识别、武器、出击、侦察、返航、降落及报告要恢复模拟后执行。

- 准备阶段始终冻结世界时间，任何一步都可返回主菜单；再次开始从开场进入。
- 港口页确认只进入驾驶，不启动首关；必须解缆并实际驶过离港线。数据加载失败保持准备页并显示错误，可返回菜单重试。
- 场景生成改变五个岛屿在固定锚点周围的位置与半径，保留固定任务和港口。港口采用矩形码头和防波堤，舰船使用点位与线段碰撞，无惯性、船体尺寸或碰撞伤害。
- 港内使用独立航行模拟，海上世界保持暂停；港内 ×10 不影响离港后的海上倍率，海上时钟从离港开始计时。
- 成功或失败后均可返回主菜单，卸载任务 CRT 并暂停世界；重试按钮暂保留现有直接重开首关行为。
- 设置已持久化，完整战役、最终结局与游戏进度存档尚未实现。会话完成目前指现有单关结算。

## 开发顺序与验收

1. **流程骨架（已接入）**：七个准备页面依序可达；确认前时钟冻结；命令先于出航；结算和失败都提供出口；再次开始清除旧页面。
2. **出港原型（已接入）**：码头出生于港区局部坐标 `(0, 0)`，北侧离港线 `y = -1.28 km`、半宽 `0.32 km`；解缆后限制 0–10 kn。撞障碍时原地停车，不扣舰体，沿通畅航线重试。这些是原型默认数值。实际离港时将局部坐标偏移、航向和速度交给首关；离港前海上战斗不运行。
3. **生成与设置（已接入）**：种子生成通过校验才允许出港，失败可重试；设置能够应用、保存与载入，默认值先填入草稿。后续扩展真实港口生成、任务布置和键位设置。
4. **叙事与教程（原型已接入）**：背景和简报来自任务数据；独立训练台验证操作，支持跳过和重播。后续制作完整开场影像、正式剧情与真实驾驶训练场。
5. **战役结束**：接入连续任务和最终结局，区分单关完成、战役胜利与永久失败，按总计划处理继承与存档。

验证范围新增设置往返读写与失败保护、种子复现、生成失败重试和离港保留种子；保留准备、港口、首关结算与战斗回归。全地形／港口／任务生成、真实船体操纵与战役结局仍未实现。

### 航向、港区与默认训练流程（2026-10-11）

- 新档与已有档默认跳过教程，从背景进入命令简报；背景／简报均提供手动教程入口。跳过不会写入完成记录，手动训练仍保留七步条件门。
- 港区扩大至 2 × 1.76 km，码头 680 × 800 m，离港通道宽 640 m；10 kn 沿中央航道约需 249 秒，可使用 ×10。地图与碰撞共用边界，泊位和仓库绘制在实体码头内。仍为点位碰撞，不代表船体尺寸碰撞已经实现。
- 母舰、港内舰船与座舱母舰标记随实际航向旋转；已确认目标使用最后观测航向，不跟随隐藏的实时转向。未知接触不显示航向。详情图默认保持标准俯视图。
