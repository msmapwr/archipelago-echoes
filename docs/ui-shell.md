# 舰桥主界面布局

参考图：[UI SVG 草图](reference/ui_wireframe_redraw.svg)。该图用于界面区域与信息层级：左侧仪表、顶部消息、中央主 CRT（雷达与状态）、右侧操作区、左下时间和底部弹药。草图中的矩形像素尺寸与其 16:9 文字标注不完全一致；实现按用户明确要求将整体逻辑画布设为 1920×1080，中央主 CRT 设为 1280×720，两者均为 16:9。

主界面按更新后的 [美学计划](archipelago_echoes_aesthetic_plan.md) 重构为作战情报中心。钢制机壳将中央单色 CRT、左侧机械仪表、右侧彩色档案监视器与纸质航海图分开；各设备使用自己的材质和信号特征，不共享一层明显的扫描线。雷达采用圆形 PPI、群岛等高线、扫描扇区和随接触信号变化的回波余辉。彩色监视器目前显示档案画面，纸图为静态导航参照，均不是实时战场视图。

菜单中央 CRT 在约两秒内完成亮度提升与自检文字，始终只有一个可操作控件：“开始游戏”。它支持键盘焦点与鼠标操作。待机时模拟暂停；按下后重置首关，将 `crt_main.tscn` 装入中央区域。游戏中，左侧仪表和底部栏跟随舰船、弹药、模式与时间状态更新；右侧状态窗显示雷达开关与链路状态。玩法操作仍在中央 CRT 内。

窗口初始为 1600×900，以便在常见桌面上完整显示。Godot 的 `canvas_items` 拉伸和 `keep` 宽高比设置在非 16:9 窗口中留边，避免界面变形。

本轮视觉实现覆盖菜单、舰桥雷达、字符终端和设备外观。美学计划中的完整电力故障、干扰、老化、可调 CRT 强度和实时彩色视频仍属后续阶段。
