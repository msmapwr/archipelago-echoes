# 舰桥主界面布局

参考图：[UI SVG 草图](reference/ui_wireframe_redraw.svg)。该图用于界面区域与信息层级：左侧仪表、顶部消息、中央主 CRT（雷达与状态）、右侧操作区、左下时间和底部弹药。草图中的矩形像素尺寸与其 16:9 文字标注不完全一致；实现按用户明确要求将整体逻辑画布设为 1920×1080，中央主 CRT 设为 1280×720，两者均为 16:9。

主界面按更新后的 [美学计划](archipelago_echoes_aesthetic_plan.md) 重构为作战情报中心。钢制机壳将中央单色 CRT、左侧机械仪表、右侧彩色档案监视器与纸质航海图分开；各设备使用自己的材质和信号特征，不共享一层明显的扫描线。雷达采用圆形 PPI、真实群岛岸线、水下等深线、设施符号、扫描扇区和随接触信号变化的回波余辉。彩色监视器目前显示档案画面；纸图共享已知海图与母舰位置，不显示隐藏敌情。数据边界见 [海图说明](map-chart.md)。

主菜单与游戏 CRT 使用相同的圆角玻璃遮罩和圆角机框；彩色 CRT 的玻璃与外框也有适度圆角。圆形 PPI 保持圆形，纸质航海图保持纸面的矩形边缘。遮罩不接收鼠标输入。

菜单中央 CRT 在约两秒内完成亮度提升与自检文字，始终只有一个可操作控件：“开始游戏”。它支持键盘焦点与鼠标操作。待机时模拟暂停；按下后重置首关，将 `crt_main.tscn` 装入中央区域。游戏中，左侧仪表和底部栏跟随舰船、弹药、模式与时间状态更新；右侧状态窗显示雷达开关与链路状态。玩法操作仍在中央 CRT 内。

窗口初始为 1600×900，以便在常见桌面上完整显示。Godot 的 `canvas_items` 拉伸和 `keep` 宽高比设置在非 16:9 窗口中留边，避免界面变形。

本轮视觉实现覆盖菜单、舰桥雷达、字符终端和设备外观。美学计划中的完整电力故障、干扰、老化、可调 CRT 强度和实时彩色视频仍属后续阶段。

2026-10-17 舰桥增强：任务标题与危险提示固定在主 CRT 顶部，危险出现时优先显示处理建议，详细任务和火控指引保留在提示／档案中；提高关键中文及操作字体。PPI 左上常驻水深／吃水，不推进模拟也可读取；顶部机壳消息同步航行危险和撞毁原因。PPI 荧光响应、字符玻璃和仅限彩屏的 RGB 遮罩分别控制，纸图与机械仪表不受影响，弱化 CRT 同时减弱这些材质效果。正常状态不新增闪烁或故障动画。证据见 [本批验证报告](bridge-navigation-qa.md)。
