# P0 单关状态与转换

首关样例流程：舰桥查看雷达 → 配置出击 → 切换等待 → 座舱 → 识别指定接触 → 返航 → 原舰、友方机场或搜救安全回收 → 结算。主角死亡进入战役失败。P0 只实现状态约束与雷达样例；出击、飞行、世界时钟及结算画面属于 P1。

| 当前状态 | 允许的下一状态 | 条件与保留的数据 |
|---|---|---|
| 舰桥 | 出击配置、结算、战役失败 | 保留舰艇/任务状态；结算需要已识别目标且指挥官已安全回收；舰上死亡则失败。 |
| 出击配置 | 舰桥、切换等待、战役失败 | 返回舰桥取消配置；舰艇和任务继续存在。 |
| 切换等待 | 出击配置、座舱、战役失败 | 完成前可取消；世界正常推进，母舰沉没且玩家仍在舰上则失败。 |
| 座舱 | 返航、战役失败 | 舰艇交由 AI，舰艇/飞机/任务状态持续变化；母舰沉没不立即结算。 |
| 返航 | 座舱、舰桥、安全回收、战役失败 | 重新飞行、回原舰或转往友方机场/搜救；沉船不可回原舰。 |
| 安全回收 | 结算、战役失败 | 记录友方机场或搜救地点；目标未确认时暂不允许成功结算。 |
| 结算 | 舰桥、战役失败 | 为后续任务预留；P0 尚无跨关逻辑。 |
| 战役失败 | 无 | 一命终止当前战役原型。 |

当前代码状态名：`bridge`、`configuration`、`switching`、`cockpit`、`returning`、`recovered`、`settlement`、`campaign_failed`。未列出的直接转换被拒绝。玩家在空中且母舰沉没时保持空中状态；安全回收之前不能结算。燃油耗尽、飞机坠毁、任务完成时仍在空中等 P1 分支须使用相同的死亡/回收约束。

时间规则：运行中正常推进；显式暂停时模拟停止，界面仍可响应继续操作。P0 雷达样例的扫描计时器随暂停停止。P1 实装切换等待时允许查看进度、取消尚未完成的切换，以及有限的舰艇航向/速度命令；托管 AI 沿用最后有效命令，异常时采用安全默认行为，并向玩家解释结果。
