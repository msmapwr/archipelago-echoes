# 《雷达指挥官：群岛空海战》游戏美学计划

## 1. 美学定位

### 1.1 核心方向

本作的整体美学定位为：

> **模拟战术终端 + 太平洋孤岛战争 + 冷战式复古未来主义**

建议使用英文方向名：

> **Analog Tactical Retro-Futurism**

中文可称：

> **模拟战术复古未来主义**

本作不追求单纯的“二战写实”或“现代军事 HUD”，而是强调玩家始终处在一套真实、笨重、不完全可靠的战争机器中，通过雷达、地图、无线电、机械仪表和有限情报理解战场。

核心美学关键词：

- CRT
- 雷达
- 等高线
- 海军航海图
- 工业机械
- 冷战电子设备
- 太平洋孤岛
- 模块化舰船
- 信息不确定性
- 黑暗舰桥
- 高亮室外环境
- 克制的军事色彩
- 复古未来主义

---

## 2. 美学核心原则

### 2.1 信息本身就是视觉主体

本作最重要的视觉对象不应只是舰船、飞机和爆炸，而应是：

- 雷达回波
- 目标轨迹
- 信号强弱
- 雷达杂波
- 地形轮廓
- 等高线
- 火控预测
- 不完整情报
- 通信日志
- 任务状态
- 系统故障
- 地图标注

玩家应该通过“读取信息”获得主要沉浸感。

雷达发现目标时，不应立即显示完整敌舰信息，而应逐步呈现：

- 方位
- 距离
- 速度估计
- 信号强度
- 分类概率
- 最后出现时间
- 是否确认

信息越不确定，画面也应越不稳定。

---

## 3. 世界观视觉统一

### 3.1 不采用严格历史年代视觉分割

游戏允许舰船和设备跨越：

- 一战
- 二战
- 冷战
- 现代
- 2050 概念技术

因此不建议完全按照历史年代分别设计几套完全不同的 UI。

建议建立统一世界观：

> 不同时代舰船都接入了一套长期迭代、标准化、模块化的海空作战系统。

舰艇外观可以明显变化，但玩家操作层保持统一。

### 3.2 不同年代舰船的视觉差异

#### 一战 / 早期舰艇

- 大量铆钉
- 裸露管线
- 大型机械表
- 黄铜或旧钢材质
- 简单火控设备
- 粗糙改装痕迹

#### 二战舰艇

- 更成熟的钢制结构
- 炮塔与舰桥轮廓明显
- 大量机械仪表
- 早期雷达
- 模块化程度开始提高

#### 冷战舰艇

- CRT 大量出现
- 雷达阵列复杂
- 电子设备密集
- 舰桥更加封闭
- 操作台趋于标准化

#### 现代舰艇

- 更简洁的舱内结构
- 综合显示设备增加
- 设备布置更规整
- 舰体轮廓更隐身化

#### 2050 概念舰艇

- 模块化面板
- 倾斜装甲
- 更强电子设备
- 新型雷达
- 激光/先进近防设备

但仍保留本作的“物理设备感”，避免变成纯透明全息界面。

## 4. CRT 与战术终端设计

### 4.1 CRT 不是简单绿色滤镜

CRT 应模拟真实电子设备，而不是只加入：

- 绿色文字
- 扫描线
- 黑色背景

建议加入轻微效果：

- 屏幕弧度
- 边缘失焦
- 磷光拖影
- 低强度扫描线
- 轻微闪烁
- 信号噪点
- 轻微烧屏
- 刷新延迟
- 信号漂移

所有效果必须克制，不能影响可读性。

### 4.2 故障直接成为 UI

系统受损时，不应只显示数值 Debuff。

#### 雷达受损

表现：

- 回波漂移
- 扫描断裂
- 雪花杂讯
- 目标重影
- 距离误差

#### 火控受损

表现：

- 提前量计算抖动
- 锁定框不稳定
- 射击预测线间歇消失

#### 通信受干扰

表现：

- 文本缺字
- 静电噪声
- 日志延迟
- 无线电断续

#### 电子地图受干扰

表现：

- 坐标偏移
- 结构位置出现误差
- 假目标
- 图层短暂错位

## 5. 色彩规范

整体颜色应非常克制。

| 用途 | 建议色值 |
|---|---|
| CRT 背景 | `#08110E` |
| CRT 信息 | `#8BE6A3` |
| 重要提示 | `#E8AF58` |
| 己方 | `#65B5E8` |
| 敌方 | `#EA6262` |
| 中立 | `#CBC8BC` |
| 危险警告 | `#E8C85C` |
| 严重故障 | `#FF4E46` |

视觉原则：

- 普通 UI 尽量使用低饱和色。
- 红色主要保留给敌方、严重故障和致命警报。
- 不应让整个界面长期高饱和。
- 舰桥环境主要使用深灰、墨绿、暗蓝、旧钢色。
- 地图主要使用米灰、蓝灰、墨黑和红蓝军事标记。

## 6. 3D 世界风格

### 6.1 Stylized Realism

建议采用：

> **写实比例 + 风格化材质 + 清晰轮廓**

特点：

- 舰船比例基本写实
- 飞机比例基本写实
- 结构轮廓清晰
- 不追求极端高面数
- 材质细节适度简化
- 远距离辨识优先

### 6.2 资产设计原则

优先保证：

1. 远距离剪影
2. 舰种识别
3. 武器位置
4. 雷达/电子设备识别
5. 损伤状态
6. 改装痕迹

其次才是：

- 铆钉
- 小型管线
- 甲板微小结构
- 高密度装饰

---

## 7. 太平洋环境

世界整体应具有：

- 辽阔
- 空旷
- 潮湿
- 炎热
- 孤独
- 危险

主要环境元素：

- 大面积海洋
- 少量岛链
- 高耸山体
- 海峡
- 潟湖
- 暗礁
- 港口
- 简易机场
- 热带云层
- 海雾

不要害怕大面积留白。

本作的信息战玩法要求玩家不能始终依靠肉眼发现敌人。

因此海洋中长时间没有可见目标是合理的。

---

## 8. 室内与室外视觉反差

这是本作最重要的场景反差之一。

### 舰桥 / CIC

特点：

- 极暗
- 低照度
- CRT 为主要光源
- 仪表灯
- 警告灯
- 金属墙面
- 设备阴影
- 机械环境感

### 飞机座舱

仍保持：

- 仪表密集
- CRT
- 机械开关
- 金属框架

但窗外应有强烈自然光。

### 室外

重点表现：

- 高亮阳光
- 蓝白天空
- 海面反光
- 热带云层
- 远处山体
- 海雾
- 强烈空气透视

形成：

> **黑暗舰桥 ↔ 刺眼太平洋**

这种反差能够强化海空身份切换。

---

## 9. 海空切换美学

本作不依赖复杂第一人称过场动画。

切换通过以下方式完成：

- 黑屏
- CRT 加载
- 倒计时
- 文字日志
- 舰内广播
- 系统提示
- 机械音效

示例：

```text
FLIGHT DECK CONTROL
AIRCRAFT #04 READY

FUEL ........ 82%
ARMAMENT .... AP / HE
RADAR ....... ONLINE

TRANSFER COMMAND TO XO

03
02
01

LAUNCH AUTHORIZED
```

其核心目标是：

> 把加载过程伪装成真实军事流程。

---

## 10. 地图视觉系统

地图应成为第二核心视觉系统。

### 10.1 手绘地图

风格：

- 海军航海图
- 米灰纸张
- 蓝灰海岸线
- 黑色等高线
- 铅笔标注
- 红蓝箭头
- 印章
- 时间戳
- 坐标
- 手写圈点

适合表现：

- 购买地图
- 玩家记录
- 最后确认位置
- 历史情报
- 过期信息

### 10.2 电子地图

风格：

- 深色背景
- 坐标网格
- 矢量等高线
- 简洁结构图标
- 数据标签
- 战术航线
- 雷达覆盖区

电子地图允许：

- 图层切换
- 干扰
- 假目标
- 坐标偏移
- 系统故障

---

## 11. 等高线视觉语言

等高线不仅是玩法功能，还应该成为品牌视觉符号。

建议用于：

- 战术地图
- 主菜单
- 加载界面
- 任务简报
- 战役结算
- 宣传图
- Logo 背景
- 地形扫描

游戏的三个核心视觉几何元素：

> **圆形雷达 + 等高线 + 坐标网格**

这些元素应贯穿整个 UI。

---

## 12. 舰船制造视觉

制造系统应该明显体现：

> **模块拼装感 / Kitbash**

不同技术年代的部件可以被组合。

因此改装后应保留明显视觉差异：

- 新旧钢板
- 不同颜色部件
- 新旧炮塔
- 外接雷达
- 临时安装支架
- 外露线缆
- 焊接区域
- 修补痕迹

### 品质视觉区分

#### 劣质

- 粗糙焊缝
- 临时支架
- 外露线路
- 不统一漆面

#### 标准

- 正常工业安装
- 配套结构完整

#### 精良

- 护罩完善
- 线缆整洁
- 安装位置规整
- 漆面统一

玩家应能仅从视觉上判断舰船的成熟度。

---

## 13. 战斗特效

战斗特效总体原则：

> **真实、短促、危险，不走街机烟花路线。**

### 炮击

强调：

- 炮口焰
- 烟尘
- 炮塔后坐
- 水柱
- 远距离闪光

### 命中

重点表现：

- 瞬间闪光
- 火焰
- 浓烟
- 结构碎片
- 系统状态变化

### 弹药库殉爆

可以成为少数真正夸张的视觉事件。

其稀有性本身能够增强震撼感。

---

## 14. 天气美学

天气首先应影响信息获取，其次才用于制造视觉效果。

### 雾

影响：

- 地平线消失
- 岛屿轮廓模糊
- 肉眼视距下降
- 雷达噪点增加
- 导航难度提高

### 暴雨

影响：

- 海面粗糙
- 可见度降低
- CRT 噪声增加
- 飞行困难
- 降落困难

### 夜间

视觉重点：

- 黑暗海面
- 极少环境光
- 机场灯
- 舰船灯
- 火炮闪光
- CRT 成为主要视觉信息源

---

## 15. 音效美学

声音是整体美学的重要组成部分。

建议重点制作：

- CRT 高频嗡鸣
- 雷达提示音
- 旋钮咔嗒声
- 机械开关
- 继电器
- 打印机
- 无线电静电
- 舰体结构低频声
- 发动机持续震动
- 甲板机械
- 炮击低频冲击
- 飞行风噪

### 广播风格

尽量冷静、专业、简短。

危险越高，系统和军官语气越克制。

### 音乐原则

不建议持续播放高强度背景音乐。

平时：

> 让机器声音本身成为环境音乐。

大规模战斗、紧急状况或重大剧情节点再引入音乐。

---

## 16. Godot Engine 实现方向

### 16.1 基本技术结构

推荐：

> **3D 世界 + 2D 战术 UI + 3D 内嵌 CRT**

### 16.2 CRT

推荐使用：

```text
SubViewport
    ↓
真实 UI
    ↓
ViewportTexture
    ↓
CRT 屏幕 Mesh
    ↓
CRT Shader
```

Shader 可包含：

- 轻度扫描线
- Barrel Distortion
- Phosphor Glow
- Ghosting
- Noise
- Glass Reflection

必须保持低强度。

### 16.3 雷达

Godot 可使用：

- `Control._draw()`
- `draw_arc()`
- `draw_line()`
- `draw_circle()`

绘制：

- PPI 雷达
- 扫描线
- 距离环
- 接触点
- 目标尾迹
- 火控预测
- 锁定框

目标数量较多时，再考虑：

- MultiMesh
- GPU Shader
- 批量绘制

### 16.4 地图

建议使用：

- Tile / Vector 混合
- 动态等高线
- 图层系统
- 地图精度等级
- 信息迷雾
- 雷达覆盖 Shader

---

## 17. UI 设计规范

整个界面需要保持统一。

### 字体

建议使用：

- 等宽字体
- 简洁工程字体
- 军事终端风格字体

尽量避免科幻装饰字体。

### 控件

主要控件：

- 旋钮
- 按钮
- 拨杆
- 机械开关
- 状态灯
- 模拟仪表
- CRT 页面

### 动画

UI 动画强调：

- 状态切换
- 信号刷新
- 扫描
- 装填
- 延迟
- 设备响应

减少：

- 弹性动画
- 大幅缩放
- 流畅商业 App 动效

系统应表现得像机器，而不是现代手机应用。

---

## 18. 战役结算视觉

战役结算继续使用雷达与军事情报语言。

推荐元素：

- 战役名称
- 雷达图
- 任务完成度
- 战损
- 侦察贡献
- 外交成果
- 时间效率
- 误击记录
- 指挥部保护
- 关键决策回放

整体感觉应像：

> 战后军事报告，而不是普通游戏奖励页面。

---

## 19. Logo 与品牌视觉

推荐围绕三个视觉符号设计：

1. 雷达圆环
2. 群岛等高线
3. 坐标网格

Logo 可以表现：

- 一个雷达扫描圆
- 圆内出现岛屿等高线
- 扫描线穿过标题
- 少量目标点亮起

品牌宣传图也尽量保持：

- 深色背景
- 等高线
- CRT 光
- 舰船剪影
- 大面积海洋

---

## 20. 情绪曲线

整个美学应服务于以下情绪：

> **孤独 → 搜索 → 判断 → 怀疑 → 紧张 → 爆发 → 安静**

玩家大多数时间并不是连续战斗。

真正重要的是：

- 等待
- 观察
- 判断
- 怀疑信息
- 做出决定
- 承担结果

因此视觉设计不能长期高刺激。

安静本身就是游戏节奏的一部分。

- 基础舰船剪影

## 22. 最终视觉设计总结

本作不应该让玩家感觉：

> “我正在玩一个海战游戏。”

而应该让玩家感觉：

> **“我坐在一套正在运行的战争机器里，通过有限且不可靠的信息试图理解远方正在发生的战争。”**

最终视觉组合为：

| 项目 | 方向 |
|---|---|
| 总体风格 | Analog Tactical Retro-Futurism |
| 中文方向 | 模拟战术复古未来主义 |
| 3D 世界 | Stylized Realism |
| 舰船 | 写实比例 + 强剪影 + 模块拼装 |
| 室内 | 黑暗、工业、机械 |
| 室外 | 明亮、辽阔、热带 |
| UI | CRT + 矢量战术终端 |
| 地图 | 航海图 + 等高线 + 网格 |
| 品牌符号 | 雷达圆环 + 等高线 + 坐标 |
| 色彩 | 低饱和军事色 |
| 特效 | 克制、短促、危险 |
| 声音 | 机械、无线电、电子设备 |
| 核心情绪 | 孤独、判断、不确定性、紧张 |

---

## 23. 一句话美学定义

> **在辽阔而危险的太平洋上，玩家坐在黑暗的舰桥与座舱中，通过 CRT、雷达、无线电和不断变化的战术地图，从不完整的信息里寻找战争的真实轮廓。**
